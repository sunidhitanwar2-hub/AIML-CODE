# AIML Assignments

This repository contains the practical assignments performed for the
Artificial Intelligence and Machine Learning (AIML) subject.

## Assignments

### Assignment 1
Identify the association between dependent and independent variables.

### Assignment 2
Apply clustering techniques using unsupervised learning.

### Assignment 3
Apply dimensionality reduction using PCA.

### Assignment 4
Apply Naive Bayes classification algorithm.

### Assignment 5
Apply KNN algorithm for classification.

### Assignment 6
Implement Linear Regression algorithm.

### Assignment 7
Implement SVM algorithm for regression.

### Assignment 8
Apply regularization to avoid overfitting.

### Assignment 9
Apply object detection from CCTV footage using YOLO and OpenCV.

### Assignment 10
Design a multimodal fake news detection model using PyTorch,
text and image feature representations, and cross-modal attention.
